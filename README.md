# StudyPlanner

StudyPlanner is a simple Android application that helps students keep track of their study tasks and progress. The application is developed gradually as part of the Mobile Application Programming course.

## Current Features

The application includes a home screen that displays a personalized greeting and study progress. Users can update the number of completed tasks using a button, which becomes disabled when all tasks are completed.

The interface is built with Jetpack Compose and uses a separate UI state to manage the displayed information. Two Compose previews are included to demonstrate different task completion states.

## Technologies Used

- Kotlin
- Jetpack Compose
- Material 3
- Android Studio
